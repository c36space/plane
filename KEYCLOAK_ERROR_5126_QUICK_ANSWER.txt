━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Because: One of these is failing:

1. ❌ TOKEN EXCHANGE FAILED (Most Common)
   - Backend couldn't exchange authorization code for tokens
   - Reason: Keycloak server unreachable, timeout, invalid code, etc.
   
2. ❌ USERINFO FETCH FAILED
   - Backend got tokens but couldn't fetch user info
   - Reason: Userinfo endpoint unreachable, token invalid, etc.
   
3. ❌ KEYCLOAK AUTHORIZATION ERROR
   - Keycloak returned error (user denied, etc.)
   - Reason: User denied access, Keycloak server error, etc.

🔍 HOW TO FIND THE ROOT CAUSE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Check API Logs (Most Important)
────────────────────────────────────────

If using Docker:
  docker logs plane-api 2>&1 | grep -i "keycloak\|error" | tail -30

If running locally:
  tail -f /var/log/plane/api.log | grep -i keycloak

LOOK FOR:
  ✓ "[KEYCLOAK ERROR]" - Shows what failed
  ✓ "Status: 500" or similar - HTTP error from Keycloak
  ✓ "Connection refused" - Keycloak not running
  ✓ "Timeout" - Keycloak too slow or unreachable
  ✓ "invalid_code" - Code exchange failed
  ✓ "invalid_client" - Wrong client ID/secret

STEP 2: Verify Keycloak is Running
────────────────────────────────────

  curl http://localhost:8080/auth/.well-known/openid-configuration

SHOULD RETURN: JSON with token_endpoint, userinfo_endpoint, etc.
SHOULD NOT RETURN: Connection refused, timeout, etc.

STEP 3: Check Backend Configuration
─────────────────────────────────────

  grep KEYCLOAK /home/kalki/plane/apps/api/.env

MUST HAVE:
  KEYCLOAK_CLIENT_ID=your-client-id
  KEYCLOAK_CLIENT_SECRET=your-secret  
  KEYCLOAK_BASE_URL=http://localhost:8080/auth
  KEYCLOAK_REALM=master

STEP 4: Verify Keycloak Client Configuration
──────────────────────────────────────────────

  1. Go to: http://localhost:8080/auth/admin
  2. Realm: master (or your realm)
  3. Clients → plane-web-client (or your client)
  4. Check "Valid Redirect URIs" includes:
     - http://localhost:8000/auth/keycloak/callback/
     - http://localhost:3000/ (if different)

STEP 5: Test Token Exchange Directly
──────────────────────────────────────

  curl -X POST http://localhost:8080/auth/realms/master/protocol/openid-connect/token \
    -H "Content-Type: application/x-www-form-urlencoded" \
    -d "code=invalid_test&client_id=plane&client_secret=secret&grant_type=authorization_code&redirect_uri=http://localhost:8000/auth/keycloak/callback/"

SHOULD RETURN: {"error":"invalid_code",...}
SHOULD NOT RETURN: Connection refused, timeout
